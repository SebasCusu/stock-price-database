# LeetCode Easy Solutions

Welcome to my repository containing my personal solutions for LeetCode Easy problems. I use this space to practice my problem-solving skills, improve my understanding of data structures and algorithms, and keep track of my coding progress.

## Tech Stack and Tools
* Language: Python 3
* Editor: Cursor / VS Code
* Version Control: Git & GitHub

## Repository Structure
Each solution is named after the problem's official LeetCode title for easy navigation:

```text
├── running_sum_1d_arr.py
├── contains_duplicate.py
└── README.md
```

## How to Run Locally
1. Clone this repository:
   ```bash
   git clone https://github.com
   ```
2. Navigate to the folder:
   ```bash
   cd my-easy-problems-leetcode-solutions
   ```
3. Run any script using Python:
   ```bash
   python contains_duplicate.py
   ```
